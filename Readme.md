# Country Explorer 🌍

A simple and interactive website built with PHP that allows users to explore different countries and discover useful information about them.

## About

This project was created as a class assignment for learning and practicing PHP.

Users can select a country from a list and view its information, including its capital, population, currency, official language, and continent.

## Features

- Country selection
- Country flags
- Capital city information
- Population details
- Currency and language information
- Clean and user-friendly interface

## Technologies Used

- PHP
- HTML
- CSS

## Purpose

This project is for educational purposes only. It was developed to practice PHP fundamentals, arrays, loops, conditional statements, and form handling.
